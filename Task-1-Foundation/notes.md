CIA Triad

CIA triad is stands for :- Confidentiality, Integrity, Availability. 
These 3 are the core pilers in the Cyber security.
1. CONFIDENTIALITY : 
Confidentiality indicates that only authorized users can access the data. In simple words "The sensitive data should be visible only to the people who are allowed to see it." 
example : The military data must be accessed by the authorized users only. If the Confidentiality is broken, the sensitive data may be theft by the enemy countries. 

2. INTEGRITY :
The Integrity denotes that, the data must be accurate, remains unchanged unless an authorized person changes it. In dimple manner "The data hasn't been tampered or modified ".
Example : If a Bank server Integrity is broken, an attacker can modify, delete or tamper the data, Which results huge lose.

3. AVAILABILITY :
Availability says that, The data should be available of the service should work when the user needs. It means the system and the data must be up state and accessible when authorized users need them.
example : If a company is getting high requests or gets DOS/DDOS attack, then it should arrange the load balancers and distribute the traffic across the systems and keep the service remain available and running to the authorized users.
